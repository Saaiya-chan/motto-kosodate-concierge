DocsGPTを日本語相談画面へ接続（2026-10-21）

使い方
http://127.0.0.1:4317/ を開く。標準はDocsGPT＋Gemini。
日本語の変換確定Enterと通常のEnterでは送信せず、Enterは改行。
「相談する」で送信。Ctrl/Command＋Enterも変換中と変換確定直後を除き送信可能。
本文の出典番号を押すと、公式の元資料が別タブで開く。回答下の出典カードは表示しない。
相談の書き出し例と、会話の流れに応じた続きの例文を表示する。例文はクリックで入力欄に入り、編集後に送信できる。

構成
日本語画面 → 同じMacのNodeサーバー → localhost:7093のDocsGPT → Gemini。
DocsGPTの既存エージェント・同じ12資料・gemini-3.5-flash-liteをそのまま利用。
現在はDocsGPTの/api/searchで検索し、Node側からGeminiへ直接、原文付きの構造化回答を依頼する。
検索用のLLM言い換えとDocsGPTによる草稿生成は行わない。ユーザーが指定した制度名と直前の質問を検索語へ補う。
回答の出典番号に実際に紐づいた資料のみ表示し、検索候補全件は表示しない。
正式な資料名と公式URLは、保存済みsource-manifestから対応付ける。
本文はDocsGPTの検索専用APIが返すチャンク全文を使用する。資料名と公式URLは取り込み済みの一覧で検査する。
本文・回答はDOMのテキストとして描画し、AIの出力をHTMLとして実行しない。
回答の表示前にGeminiで意味を確認し、引用原文の存在と制度範囲を機械的に照合する。複数制度のPDFでは、引用した節の見出しも判定する。
一致しない説明はリンクだけを消すのではなく、説明自体を修正または除く。相談文・確認項目などの提案に不要な引用を付けない。

接続設定
.private/docsgpt-agent.json にある既存のエージェントキーをサーバーだけで読み込む。
GeminiのAPIキー、エージェントキー、DocsGPTの生の会話IDはブラウザへ返さない。
ブラウザは、このサーバーが発行した期限付きセッションIDで会話を継続する。
未知・期限切れのセッションIDや履歴の不一致を拒否する。
サーバー再起動後は「最初から」で新しい相談を開始する。

保存
画面の履歴はページ内のみ。現在の検索専用経路ではDocsGPTに検索語のトレースが残るが、会話全文や草稿は保存しない。
Googleへの会話・関連資料の送信も行う。画面下の説明をこの動作に合わせて修正。
Node側は会話本文を永続化せず、履歴ハッシュと公開資料の検証用本文をメモリで管理。
次の回答に使う履歴は、画面へ返した検証済みの回答をGeminiへ渡す。DocsGPT側の未検証の草稿は再利用しない。
比較用にDOCSGPT_PIPELINE=legacyで起動すると、従来の/api/answer→校閲の経路を使う。この場合はDocsGPTに草稿が残り、最終表示と異なる。
最新の速度・出典検証はDOCSGPT_PERFORMANCE.txtを参照。

起動
1. evaluation/docsgpt/ で次を実行する。
   docker compose --env-file ../../.private/docsgpt-eval.env -f compose.yaml up -d
2. support-finder/ で npm start
標準起動では不要なRuriモデルを読み込まない。Ruri比較用の事前ロードはnpm run start:ruri。
初回DocsGPTのDB初期化でbackendが停止した場合は、初期化終了後にbackendを再起動。

ブラウザ実会話の確認記録は evaluation/docsgpt/results/integration-qa.txt に保存。
日本語IMEの実際の候補ウィンドウをOS上で操作する試験までは行っていない。
実ブラウザの通常Enterで未送信・改行を確認し、変換イベントの回帰試験でIME条件を確認。

実ブラウザの5往復（2026-10-21）
1. 全国同じ料金か → 市町村設定であり一律ではない。FAQを引用。1.6秒。
2. 9,210円・4,200円は本人負担か → 運営費等の基準で本人の料金ではない。FAQを引用。3.3秒。
3. 1泊2日で確認する費用 → 市町村で利用料を確認と回答。FAQを引用。2.8秒。
4. 明日利用・総額・食費・減免の電話相談文 → 希望を含む具体的な文を作成。4.3秒。
   補足文には誰でも通園・訪問支援の資料を選んでおり、意味としての引用不整合が残った。
5. お礼・市に電話する旨 → 応援する短い返答で自然に終了。3.3秒。
会話途中で「登録資料では確認できません」だけの打ち切りや、別制度への話題の切り替わりはなかった。
出典番号から該当カードが開き、全文の取得と公式PDFのURLの対応を確認した。
今回改善したのは接続、日本語入力、出典の表示・本文取得であり、DocsGPTの引用選択を保証する修正ではない。
